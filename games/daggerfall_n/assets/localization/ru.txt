# Daggerfall N — строки интерфейса (Правило 5: текста в коде не бывает).
# Формат: ключ=значение, по одной паре в строке, UTF-8. Строки, начинающиеся
# с #, и пустые игнорируются. Ключ хешируется через serialization::fnv1a64,
# то есть тем же самым кодом, что и в игре — одна реализация на всех.
#
# Это ВРЕМЕННЫЙ формат. Он уедет в общий загрузчик содержимого, как только
# у core появится чтение JSON; ключи и значения при этом не изменятся.

# Отладочные оверлеи редактора (В28): статистика кадра и что под прицелом.
#
# ФРАЗЫ ЦЕЛИКОМ, А НЕ СКЛЕЙКА ИЗ СЛОВ. Строки читает человек, который спросил
# «трис (что это такое)», и ответом должно быть предложение, а не мнемоника.
# Числительное стоит ПОСЛЕ существительного («треугольников 1476»), а не перед
# ним: по-русски счётная форма меняется на 1, 2 и 5, и склейка «%d треугольник»
# была бы сломана в двух случаях из трёх — в переводе, который никто не
# перечитывает. Порядок «что это: сколько» заодно снимает вопрос, к чему
# относится число.
#
# Каждая строка идёт парой: полная и КОРОТКАЯ. Короткая нужна не для красоты —
# 320x180 это разрешение, которое страница настроек предлагает соседней
# строкой, и полная фраза туда не входит. Выбор между ними — ЗАМЕР ширины
# (fits_width), а не ветка по числу 320.
