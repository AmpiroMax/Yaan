#
# ЗДЕСЬ — ТОЛЬКО ТО, ЧТО НЕЛЬЗЯ ПОСЧИТАТЬ. Класс тела и вещество — это
# ФАКТЫ О ПРЕДМЕТЕ («миска глиняная»), их неоткуда взять, кроме как
# назвать. МАССА ЗДЕСЬ НЕ ПИШЕТСЯ: она считается при загрузке из
# собственных треугольников предмета и плотности вещества
# (engine/app/sources/PropPhysics.*), потому что написанная рядом масса
# протухнет молча в день, когда кузница перепечёт предмет на сантиметр
# шире.
#
# ФОРМАТ: имя  класс  вещество  тело  # заметка
#   класс   — fixed (обстановка: дом, стена, очаг, кровать, стол)
#             loose (утварь: своё динамическое тело Jolt, спит, пока
#             не тронут; его можно взять, нести, бросить, сложить)
#   вещество— имя из таблицы плотностей (PropPhysics.cpp)
#   тело    — solid (брусок, каравай, полено) либо ТОЛЩИНА СТЕНКИ в
#             миллиметрах у полой вещи. Полая вещь — это площадь
#             поверхности на толщину стенки, а не габарит: сундук по
#             габариту 0.31 м³ дубом весил бы 217 кг, настоящий — 15-25.
#   заполн. — НЕОБЯЗАТЕЛЬНОЕ пятое поле: какая доля НАРИСОВАННОГО объёма
#             есть вещество. Пусто = 1. Это не подгонка под желаемое
#             число, а признание замера: кузница печёт брус вдвое толще
#             настоящего (у стула полки дерева 0.0223 м³, у настоящего
#             стула той же формы — 0.011; у стола 0.167 против 0.078).
#             Отношение в обоих случаях около двух, потому что причина
#             одна — сечение бруска в рецепте. Столбец уйдёт к единице,
#             когда кузница станет точнее; у оболочки он не нужен —
#             там долю вещества уже назвала толщина стенки.
#
# ЧТО НЕ НАЗВАНО ЗДЕСЬ — FIXED. Умолчание выбрано так, что мир без этого
# файла ведёт себя ровно как вчера: всё стоит, ничего не падает.
#
# ГРАНИЦА С ВОЛНОЙ «СИДЕТЬ И ЛЕЖАТЬ»: предмет, на котором сидят или
# лежат, НЕ БЫВАЕТ loose. Кровать, лавка, стул и кресло несут точку позы,
# посчитанную по их месту, и уехавшая из-под сидящего лавка — дефект, а
# не физика. Ровно эту же границу проводит Skyrim: мебель статична,
# утварь — клаттер.
#
# ТАБЛИЦА ВРЕМЕННАЯ В ОДНОЙ СВОЕЙ ЧАСТИ: колонка «вещество» переедет в
# ось 1 материалов, когда та придёт (artifacts/reports/materials-spec).
# Колонки «класс» и «тело» — свойства ПРЕДМЕТА, они останутся здесь.
