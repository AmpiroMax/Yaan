#
# Key items:
# - DFN_BODY_PROBE=mirror is self-driving, so the "restore" here is the probe
#   recipe rather than a DFN_RESTORE pose file: the probe spawns the double at
#   spawn + (0,0,-3), warms up 4 s, aims the eye at it, and shoots at yaw
#   offsets 0 / -0.25 / -0.5 rad. Frame 00 (offset 0, the double square-on) is
#   the silhouette shot; the archived pair is frame 00 from each arm.
# - DFN_MIRROR=1 IS REQUIRED and is easy to miss: DFN_BODY_PROBE=mirror selects
#   the probe's camera behaviour but does NOT spawn the puppet, so without it
#   the probe photographs an empty clearing and the frame looks like "the body
#   is not drawing". Cost one shoot to rediscover.
# - DFN_STAND=1, not the default 0: at stand 0 the double now spawns behind
#   testbed geometry that arrived after the earlier mirror frames were taken.
#
# Dependencies:
# - Uses: engine/app's DFN_BODY_PROBE (App.cpp, gated).
# - Used by: docs/specs/character.md item b.
#
# AI Agents Notice (must follow):
# - Follow docs/ARCHITECTURE.md strictly.
# - Do NOT "improve" the vantage. Both archived frames were shot from THIS
#   recipe; changing it silently invalidates the comparison rather than
#   improving it.
# - THE ZOOM IS PART OF THE EVIDENCE, not decoration. The change moves the arm
#   3.4 cm clear of the trunk at mid-chest, which is 5 px at this range on a
#   640x360 frame — legible only at the 5x nearest-neighbour blow-up. A
