# Синк №1 — этап «Контракты» завершён

**Дата:** 09.08.2026, ночь. **Участники:** лид (Fable), core, render, sim (Opus 4.8).
**Длительность этапа:** ~15 минут параллельной работы трёх агентов (≈355k токенов суммарно).

## Что построено

62 файла: три техспеки по семь разделов ([core](../specs/core.md), [render](../specs/render.md), [sim](../specs/sim.md)), публичные заголовки всех девяти платформенных и движковых модулей, документация модулей. Ни одного `.cpp` — дисциплина «контракты первыми» (Q38) выдержана всеми.

Ключевые контракты:
- **ECS** (core): наследие Quicky + `spawn_batch`/`destroy_group` и индекс сущность↔чанк (Rule 11)
- **`HeightFieldView`** (core/math): формат передачи рельефа world→render/physics; uint16-высоты, метры через scale/offset на чанк, общие краевые ряды против щелей между чанками
- **`NpcAction`** (sim): закрытый `std::variant` из семи действий, очередь с монотонными номерами, `enqueue()` — единственный вход. Скрипт, тесты, редактор и будущая LLM кладут одинаковые значения (Q70, Rule 15). Журналируемо для реплея (Rule 13.3)
- **Диалоги** (sim): реплика = стабильный id + условия + сегменты (текст, тон, громкость, скорость, тег); хеш сегмента FNV-1a «заморожен навсегда», 16 hex + `.opus` — имя аудиофайла (Q79)
- **Общие компоненты** (лид): Transform/PreviousTransform, CameraPose/PreviousCameraPose, RenderMesh, LocalBounds, HoverTarget-ресурс
- **Пины зависимостей**: Jolt v5.2.0, ozz 0.16.0, miniaudio 0.11.22, llama.cpp b5013, bgfx.cmake (тег фиксируется на этапе 2)

## Как шла координация

Агенты договаривались напрямую, без лида, ровно как задумано в Q33: контракт интерполяции sim↔render (снапшоты prev/curr на фиксированном тике, блендинг по альфе), конвенции скиннинга, поверхность ECS. Через лида прошли: общие компоненты (зона лида), константы (NUMBERS.md), ретрансляция в sim, пока тот не был адресуем. render поймал нарушение хедер-контракта в файле лида — исправлено.

## Решения синка

| Вопрос | Решение | Отвергнуто |
|---|---|---|
| Интерполяционное состояние | два компонента (Transform + PreviousTransform) | prev-поля внутри Transform — системы без интерполяции не должны платить за них |
| Идентификаторы ассетов в RenderMesh | плотные id из реестра (uint32), хеш живёт только в реестре имя→id | обрезка FNV-64 до 32 бит — риск коллизий на тысячах ассетов |
| LocalBounds | остаётся raw min/max | обёртка над math::Aabb — render уже потребляет поля напрямую, обёртка ничего не покупает |
| Подсветка взаимодействия | ресурс `HoverTarget{EntityId}`: gameplay пишет (raycast через IPhysics), render читает | подъём Highlightable в core — это геймплейная семантика, ей место в gameplay |
| gen_constants | подтверждено: `<build>/dfn_generated/Constants.h`, `dfn::config`, inline constexpr, имена NUMBERS.md дословно | — |
| Новые константы | SIM_MAX_CATCHUP_STEPS=5, CHUNK_LOAD/UNLOAD_RADIUS=2/3, NPC_ARRIVE_RADIUS=0.5, INTERACT_DISTANCE=3.0, CAMERA_PITCH_LIMIT=1.55 рад — все предварительные | — |
