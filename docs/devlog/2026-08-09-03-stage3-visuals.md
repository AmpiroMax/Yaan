# Синк №3 — Этап 3 «Визуальный фундамент» закрыт

Дата: 09.08.2026, ~10:40–13:20. Участники: lead, core, render, design (новый агент), sim (без задач этапа).

## Что построено

- **Worldgen v2** (core): 6 проходов — макро-штампы (Ravenscar Crag L0 ~52 м),
  гидрология (монотонная река, pond-and-spill озеро), классификация поверхности
  (sand/rock/water-bed/dryness), сайты (7 типов зданий по назначению),
  мезо-скаттер (3 вида деревьев, кусты, цветы, трава, камни), микро.
  Детерминизм закреплён тестами; ~30 мс/чанк после оптимизаций (было 0.5–0.8 с).
- **Рендер-визуал** (render): процедурные текстуры без файлов-картинок, сплат по
  правде поверхности (вершинные веса), вода по телам (озёрные веера, ленты реки),
  атмосфера/туман/небо, палитровый пост 64 цвета + дизеринг Байера 4×4,
  плейсхолдер-меши сайтов, тур v3 с ground_relative-камерами.
- **LANDSCAPE.md** (design): библия ландшафта — правило треугольника BotW, weenie,
  иерархия L0/L1/L2, читаемость силуэтов в пикселе, интервалы POI от времени пути.

## Цикл «находка → вердикт → фикс» (первый полный)

render отсмотрел кадры и подал три находки; design вынес вердикты; core исполнил:

1. **Скала утоплена в соснах** → кроно-зрячая проверка видимости C1 +
   LANDMARK_CLEARANCE_FACTOR 1.2 + смотровые клинья P5. Корень: замкнутое
   сосновое кольцо не проходит такую проверку никогда — заменено на 4 радиальные
   гребневые полосы. C1 сида 1 = 0.618 ≥ 0.6. Скала теперь читается с Vaelmere.
2. **Броды не на реке** → таблица бродов удалена; броды выводятся из
   сгенерированной трассы (пересечения коридоров + добивка по FORD_SPACING_MAX),
   дно реально поднимается, глубина коридора ≤ FORD_DEPTH_MAX — тест.
   Новое правило: привязки к воде только выводятся, никогда не таблируются.
3. **Грязевые разливы/«озеро больше макета»** → это был расползшийся пруд;
   вода за пределами max(SHORE_SAND_DIST, 2×ширина) от трассы осушается
   (2.74% → 2.30% мира), полоса грязи — тестовый инвариант.

- **Разрешение и палитра — пользовательские настройки**, не константы:
  settings.cfg автогенерится при первом запуске (internal_resolution, palette),
  env DFN_* поверх для туров. Позже — экран настроек.
- **feature_requests.md** (корень) — личный файл хотелок пользователя: освещение и
  тени, объём микрорельефа, вытянутые холмы-гряды (принято: правило анизотропии
  §2.1 + HILL_ANISOTROPY 2.5, ретюн P1 у core следующим), приложение
  .app с меню/иконкой, команда сценаристов (маршрутизация у lead).
