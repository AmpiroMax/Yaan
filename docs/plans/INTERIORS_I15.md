# И15 — Интерьеры-локации. Исполнительный свод

Полная спецификация — в отчёте агента epoch-i15 (сессия 24.08). Здесь — свод
для исполнителей волн; при расхождении чинить свод, а не изобретать заново.

## База (замеры)
Вайтран: 1087 [house] / 205 мебель / 24 очага+24 пламени+24 [light]-очага;
построек СО ВХОДОМ ~26 (13 рецептов с FURN). Ключ ячейки пакетирования
различает XZ только в полосе −256…1792 м — КАРМАН ТОЛЬКО ПО Y. Пол печки
sky_visibility 0.30 — для интерьера НЕ годится (нужна полная сфера, пол 0.05).
Интерьеры УЖЕ проходимы через дверной проём (створка вне коллайдера
намеренно) — И15 это ПЕРЕНОС в локацию + запечатывание, и приёмка мерит
именно это (та же кровать с той же точки, но через дверь).

## Модель
- Интерьер = обычный .scene: assets/scenes/int/<город>/<slug>.scene.
  Координаты СВОИ от (0,0,0), пол y=0. Никаких новых форматов/парсеров.
- Геометрия по волнам: А — тот же .dfh целиком в кармане; Б — подмножества
  по новому параметру элемента side (0 both / 1 ext / 2 int), одна правда о
  доме; В — свои рецепты полостей (пещеры — всегда так).
- Пещеры/штольни = int-локация без дома; портал на рельефе, рамка — обычная
  наружная постройка. Запрет «высотное поле не держит полостей» снимается
  тем, что полость в нём не живёт.
- Формат (только добавления): [portal] at/to/to_spawn/radius_m; [spawn]
  name/pos/yaw; ключ [house] interior=<путь>. to=^back — обратная дверь.
  Старый движок обязан читать новую сцену без ошибки (проверить круговым
  прогоном первой рукой волны А).

## Переход
- Город НЕ выгружается: подвес (world_suspended_: не рисуем
  террейн/небо/траву/потоки экстерьера, chunks_.update заморожен, физика
  города не трогается) + карман (centre_x, −1000, centre_z) + страховочная
  плита −5 м. Второй слот отрисовки set_interior_mesh + СВОЁ тело Jolt.
- Цели: вход ≤0.5 с, выход ≤0.05 с. Шторка 0.15 с в обе стороны
  (DFN_INTERIOR_FADE, 0 = побитово сравнимые кадры).
- ИНВЕРСИЯ КОЛЛАЙДЕРА ДВЕРИ: флаг portal=1 у дверного элемента вводит
  створку в коллайдер (иначе после запечатывания игрок пройдёт сквозь
  оболочку). Двери без флага — как были.
- Возврат: записанная точка активации +0.6 м наружу по нормали, yaw+180°.
- InteriorState { scene_path, visited, door_open, return_pos, return_yaw,
  taken_items(пустой контейнер на будущее) }.
- Вложенность в волне А запрещена (один активный интерьер).

## Убранство и свет
- furnish() → furnish_interior(): та же локальная раскладка FURN/FLOOR
  (НЕ переводить в мировые координаты — просьба к И1 отправлена), очаг без
  interior=1 и без room (снаружи нечему течь).
- Ambient из [air] ambient + ambient_darkness (крюки есть); солнце в ноль.
- Печка bake_house_ambient_occlusion: полная сфера, пол 0.05, тот же кэш
  (второй клиент И10).
- Бюджет: ≤8 настоящих [light] на локацию, ≤1 теневой; остальное — glow
  (механизм готов). ГРАБЛИ FINDING_DUNGEON_DARK: теневой слот ближайшему
  очагу — только после замера (пламя не кастует само на себя).

## Оболочка снаружи
Окна остаются глухими и светящимися; признак «горит» берётся ИЗ int-сцены
(есть [light] radius>0). После миграции дверной проём перестаёт быть
законным сквозным просветом: --shell падает в ноль на КАЖДОМ доме.

## Приёмка (семь рук)
1 проходимость капсулой от [spawn] до порталов и мебели (сетка 0.25);
2 мебель на полу (низ на треугольнике пола ±0.05); 3 связность (готова);
4 герметичность --shell изнутри; 5 дверь достижима с обеих сторон;
6 парность interior=↔int-файл↔^back, ни одной сироты; 7 бюджет огня.
Двери: DFN_INTERIOR=<путь> (открыть карту сразу внутри — для беспилотных
кадров), DFN_INTERIOR_FADE. Прибору И0 — плечо «время входа/выхода, мс».

## Волны
- А (С, 2–4 сессии): формат → карман/подвес/слот → портал+шторка+возврат →
  ambient+печка → ПИЛОТ один дом (city-house-s у рынка, тот же .dfh, ноль
  новой геометрии) → приёмка руками 1/2/5/6 + кадр DFN_INTERIOR + замер
  времени. Доказывает механику; если не выйдет на одном доме — не выйдет
  и на 5500.
- Б (С): side в кузне (ПОСЛЕ И3), furnish_interior в gen_city, 26 int-сцен
  Вайтрана, запечатывание, окно-по-правде, полная приёмка, кадры до/после
  одной точкой.
- В (С–Б): портал без дома, рецепты полостей (коридор/камера/ствол/свод),
  многокомнатность (room возвращается как разделитель огня), клиенты:
  Айронделв (6 штолен, храм-грот), Клифтспан (тюрьма-яма), ледники/подклеты.

## Пересечения
И1: писать сцену функцией, вызываемой N+1 раз; furnish локальный. И3: side
после неё. И6: интерьерное тело — репетиция разбиения. И10: второй клиент
кэша AO. И16: клеть Айронделва = портал с анимацией, не платформа.

## Открытые вопросы владельцу
1. Шторка 0.15 с или бесшовный вход (бесшовный = второй проход отрисовки +
   портальное отсечение, отдельная большая волна)?
2. Интерьер БОЛЬШЕ оболочки — разрешаем (по-скайримски, но источник
   «интерьер не совпадает с домом»; волна Б дорожает ~вдвое)?
3. «Все дома» буквально (~460 интерьеров на город) или правило «вход имеет
   постройка с жильцом/назначением, остальные — дверь-декорация» (Skyrim
   делает так)?
4. Верхние этажи: одна локация на дом с лестницей внутри (предложение) или
   локация на этаж?
