## Вне git — `artifacts/`

`artifacts/reports/` — отчёты волн с кадрами; `artifacts/acceptance/` — приёмки и кадры до/после;
`artifacts/reference/` — референсные кадры и фото; `artifacts/devlog/` — журналы; `artifacts/misc/`.
Папка в `.gitignore`. Отчёт волны кладётся в `artifacts/reports/<тема>/`, а в BACKLOG.html
попадает только итог (статус тикета и две строки обновления). Ссылка на отчёт из docs —
относительным путём `../artifacts/...`; такая ссылка работает только локально, и это нормально.

## Что запрещено

- Бинарники (png/jpg/mp3/pdf/log) в `docs/` — хук не пропускает новые.
- Журналы UPD и метки времени в шапках (правило 17).
- Новые файлы в корне `docs/` — только в подпапки из таблицы.
