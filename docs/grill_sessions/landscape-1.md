# Гриль-сессия: ландшафт, красота, живой мир

Направление задано пользователем: красота и ощущение живого мира ВАЖНЕЕ
взаимодействия с персонажами. Ориентир — Skyrim: ходить, смотреть на погоду и
пейзаж. Отдельные карты-стенды под каждый ландшафт. Ощущение шага вместо
парения. Руки и ноги видимы. Дорожки, выложенные камешки, цветы, мох.
Исследование правил красивых миров запущено (LIVING_WORLD_RESEARCH.md).

## Раунд 1

- **в1** Формат карт → **отдельные карты** (стенды, строящиеся правилами
  генерации, чтобы позже сложиться в один мир).
- **в2** Первые карты → **лесок + река/берег**, причём на реке должен стоять
  ЗАМОК БОЛЬШИХ РАЗМЕРОВ.
- **в3** Ощущение шага → **все четыре**: покачивание камеры, звук шагов по
  поверхностям, видимые ноги + тень, мелочи веса (приземление, оседание,
  противофаза рук).
- **в4** Погода → **все четыре**, ОБЛАКА ПЕРВЫМИ; туман, ветер-состояние,
  погодные зоны следом.

## Раунд 2

- **в5** Замок на реке → **(б) новый, на отдельном стенде**; вылизанным заменит
  Харроувард в большом мире.
- **в6** Город → **сразу с городом** (стена, город внутри, посад снаружи,
  пристань). РЕКУ ДЕЛАТЬ БОЛЬШЕ — «не как лужица что сейчас».
- **в7** Дорожки → **все четыре типа** как одна система (мостовая, грунтовая,
  тропинка-намёк, каменные ступени).
- **в8** Обочина → **(а)+(в)**: жизнь у дорог и воды + редкие жемчужины в глуши.
- **в9** Рельеф → **(а)+(б)**: волны 0.3–0.6 м везде + холмистость 2–5 м,
  ложбины и гривы; одна равнина сохраняется нарочно.
- **в10** Облака → **все три вида сразу**: слои, тени по земле, кучевые на
  горизонте.
- **в11** Тело → **(а) ПОЛНОЕ ТЕЛО от первого лица**. Плюс отдельная
  микро-карта «зеркальный персонаж»: крошечный кусок земли, напротив стоит
  собственный персонаж и зеркалит движения (я влево — он вправо), и режим
  техно-демо: висит в воздухе и показывает анимации. Стенд для анимаций.
- **в12** Звук → **всё** (шаги, ветер, листва, вода, живность), музыка позже.
- **в13** Море → **плоское сейчас, но с ВОЛНАМИ** — небольшими и средними,
  без пены (пока).
- **в14** Техдолг → **вперёд**, до карт.

## Раунд 3 — все рекомендации приняты («со всеми пунктами согласен»)

- **в15** Река → **(б)** 25–35 м, судоходная, настоящая долина с террасами,
  ручьи-притоки 3–5 м для контраста.
- **в16** Агент-персонажник → **да**, после техдолга, параллельно картам.
  Первая задача — зеркальная карта.
- **в17** Капельная эрозия → **берём** (промоины, лощины, веера выноса).
- **в18** Словарь именованных форм рельефа → **да**; карта = композиция форм.
- **в19** Шесть правил красоты → **в библию как приёмочные условия**:
  (а) тропа прячет цель хотя бы раз; (б) тропа соединяет настоящие цели почти
  кратчайше; (в) богатая обочина на кромке; (г) кучность — авторское поле;
  (д) средний ярус холмов прячет сюрпризы; (е) правило находки.
- **в20** Частота находок → **~60 с ходьбы** база; у дорог чаще, в глуши реже.
- **в21** Волны → **Герстнер, 3 волны, от общего поля ветра**, у берега гаснут
  по глубине; на реке течение, не волны.
- **в22** Морская карта → **третьей**, сразу за рекой.
- **в23** Техдолг → **(а)+(б)+(в)+(г)**: разбиение рендера, пруд как плоский
  плёс, два красных теста, чтение JSON. Сохранения отложены.
- **в24** Дорожки → **core генерирует, render рисует, flora населяет обочину,
  design принимает**. Без нового агента.

## Порядок реализации

Техдолг → лесок + река с замком (персонажник параллельно) → море со скалами →
городок, зеркальная карта. Вопросы пользователю не задавать без крайней нужды —
прямое указание: «давай реализовывать».
