
# docs/research/rpg — рисёрч по чужим RPG (август 2026)

Собран лор-сессией 27.08.2026 девятью веб-разведчиками под дудос-прожарку
«что нужно для хорошей RPG». Сохранено по распоряжению владельца, чтобы не
делать рисёрч дважды. Внутри каждого файла — источники и честные пометки
«ДЫРА» / «не подтверждено»: непроверенные числа НЕ КЛАСТЬ в дизайн-доки
без перепроверки.

## Главные предостережения из всего корпуса
1. Мир не должен расти быстрее бестиария (Elden Ring).
2. Генерацией можно гейтить, нельзя кормить бесконечно (Радиант vs Престон Гарви).
3. Не вводи стат без собственного глагола (Несмит).
4. Провал проверки должен быть контентом, не стеной (NV/Disco).
5. Плотность имеет цель: «правило 40 секунд» (Witcher 3).
6. Маркетинговые числа концовок — перестановки, не финалы (BG3 17 000 → «низкие двузначные»).
