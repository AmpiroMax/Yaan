# 2D-силуэт → 3D-меш: алгоритмы, открытый код, лицензии

Разведка 27.08 по заказу владельца о 3D-гербе в главном меню.
**Нейросетевые методы не рассматривались** — только классическая геометрия.
Разбор, кадры и выбор — в `docs/reports/heraldry-3d.html`.

## Правило проекта

GPL — **нельзя** (ни в рантайм, ни в офлайн-инструменты, которые мы
распространяем). Можно MIT / BSD / Apache-2.0 / ISC / BSL-1.0 / public domain.
MPL-2.0 — можно (копилефт пофайловый). LGPL — избегаем.
**Инструментом** (не источником кода) пользоваться можно чем угодно:
результат работы Blender/OpenSCAD принадлежит нам, GPL накрывает приложение,
а не то, что в нём сделано.

## Алгоритмы по сути

**Точное евклидово преобразование расстояний (EDT).**
Фельценсвальб — Хуттенлохер, *Distance Transforms of Sampled Functions*
(Theory of Computing 8(19), 2012, CC-BY): квадрат расстояния — это нижняя
огибающая парабол, поставленных в каждый отсчёт; проход по строке за O(n),
двумерный случай сепарабелен. Альтернативы той же точности: Мейстер (2000),
Маурер (2003). Приближение чамфером (Боргефорс, веса 0.955/1.3693 в OpenCV) даёт
~2% ошибки — на пологой фаске она видна гранями, поэтому берётся точное.

**Расстояние → высота.** `t = clamp(d/R, 0, 1)`:

| Профиль | Формула | Как читается |
|---|---|---|
| круглая фаска («подушка», монета) | `h = H·sqrt(1 − (1−t)²)` | у края уклон вертикальный — острый обод, ловит узкий блик |
| синус | `h = H·sin(πt/2)` | мягче, уклон конечный |
| прямая фаска (чамфер) | `h = H·t` | станочный скос, одна жёсткая складка |
| smoothstep | `h = H·(3t²−2t³)` | восковая печать, гладко с обоих концов |
| степенной | `h = H·t^α` | α<1 пухлее, α>1 площе |

Клип `min(d,R)` даёт «фаска по краю + ровное поле»; без клипа (`R = max d`) —
подушка на весь силуэт. Это же слово в слово делает узел `Bevel` в Substance
Designer («строит поле расстояний и по нему скашивает края в 3D») и операция
`Inflate` в ZBrush.

**Нормали из поля высот.** Центральные разности
`n = normalize(−∂h/∂x, −∂h/∂y, 1)` (делить на МИРОВОЙ размер тексела, иначе
уклон зависит от разрешения) либо Собель. У EDT есть гребень по срединной оси
и ступенька по краю — на обоих разностная производная шумит, лечится
размытием `h` на ~1 тексел ПЕРЕД дифференцированием.
Аналитический путь: `∇h = f′(d)·∇d`, где `|∇d| = 1` почти всюду.

**Родня по смыслу.** *Teddy* (Игараси, SIGGRAPH'99) надувает силуэт по
хордовой оси, и сечение там — та же четверть овала, что и «подушка».
*Lumo* (Джонстон, NPAR'02) обходится вообще без высоты: задаёт нормали на
контуре и диффундирует их внутрь — годится, если нужна только карта нормалей
на плоском щите.

## Как устроена эмблема в Skyrim (проверено по разборам модеров)

Это **настоящий 3D-меш** `meshes/interface/logo/logo.nif`, не билборд.
Рельеф в основном живёт в **карте нормалей** `logo02_n.dds`, а «дорогой
металл» даёт **кубическая карта окружения** в материале, а не густая
геометрия. Вращение: вариант вручную — полный оборот за 8 с (~45°/с);
у ванильной эмблемы дрейф ещё медленнее.

**Вывод для нас:** правильная боевая форма — низкополигональная плита с
запечённой картой нормалей плюс отражение окружения. Наш плотный меш — это
«высокополигональный исходник», с которого такую карту пекут.

## Что взято в наш инструмент

Ни строки заимствованного кода: разрешённое (earcut, CDT, Clipper2) пришлось
бы ставить пакетами, которых в системе нет — здесь нет даже Pillow, — а
алгоритмы школьные. `tools/gen_heraldry.py` стоит на numpy и стандартной
библиотеке: свой читатель PNG, свой EDT по статье, марширующие квадраты как
мешер, свой писатель `.dfo`. Дуглас — Пойкер реализован и измерен, но в боевом
пути не применяется (почему — в отчёте).
