# Удары, толчки, сбивание с ног, регдолл — дизайн (записка до кода, 04.09.2026)

Ответ на вопросы владельца 04.09 («что будет, если прилетит тяжёлый блок; закон
сохранения импульса; регдолл; болванчики») по рисёрчу
docs/research/HIT_REACTIONS_PHYSICS_RESEARCH.md. Зоны: контракт физики — лид
(IPhysics/JoltPhysics), тело/анимация — линия персонажей (anim/app), стенд —
приборы.

## 1. Что есть сегодня (честно)

- Игрок — CharacterVirtual: кинематическая капсула. Он толкает тела силой
  push_force_n = 100 Н, но контракт IPhysics не отдаёт ему ни импульса от тел,
  ни массы, ни контактов. Тяжёлый блок, прилетевший в персонажа, СЕГОДНЯ
  остановится о капсулу, как о стену; персонаж не сдвинется ни в одну
  сторону. Это не свойство Jolt (у него mCanPushCharacter = true по
  умолчанию), а дыра нашего контракта.
- Закон сохранения импульса при ударе персонажа по НПС не работает: удара
  как физического события нет — есть хитбоксы (anim::HitboxSet) без обмена
  импульсом.
- Регдолла нет; болванчиков нет.

## 2. Модель: три яруса реакции (как в Skyrim/Dark Souls, с честной физикой снизу)

Импульс J (Н·с) приходит от чего угодно: удар оружием (масса оружия × скорость
клинка на кадре контакта, из хитбокс-контакта), толчок тела Jolt (из
контакта капсулы: масса × относительная скорость, ограничено), заклинание.
Дальше — СТОЙКОСТЬ (poise, как невидимая полоса Dark Souls; ресурс как
усталость Oblivion):

| Ярус | Условие | Что происходит | Откуда взято |
|---|---|---|---|
| 0. Толчок | любой J | капсула получает Δv = J/m (m = масса тела из реестра, ~80 кг) — ВСЕГДА, в любую сторону; ноги — по §11 LOCOMOTION_GROUNDED (стопа держит трением, пока может нога, потом переступ) | Jolt mCanPushCharacter, Euphoria «attempt to stay standing» |
| 1. Стаггер | J_poise > POISE_HEALTH_NOW, но J < KNOCKDOWN_J | анимация-реакция по направлению удара (Mixamo Hit Reaction есть в паке Sword and Shield), действие обрывается, стойкость обнулена; стойкость восстанавливается через POISE_REFILL_S без ударов | Skyrim stagger «interrupts whatever action», DS poise «when it hits 0, your character will stagger», «after 5 second […] refill» |
| 2. Сбивание с ног | J ≥ KNOCKDOWN_J (относительно массы: J/m ≥ KNOCKDOWN_DV, ~2,5 м/с) или стойкость ниже нуля при ударе | АКТИВНЫЙ регдолл: тело — Jolt Ragdoll из хитбоксов (anim::HitboxSet → тела + констрейнты по скелету), импульс всем телам (Ragdoll::AddImpulse по хитбоксу попадания), моторы тянут к позе «падение» (DriveToPoseUsingMotors) с силой, спадающей до нуля за KNOCKDOWN_LIMP_S; лежит, пока скорость тел не сойдёт; встаёт клипом «get up» из позы регдолла (GetPose → ближайший кадр клипа) | Skyrim ragdoll «knocked helplessly to the ground and will have to wait a few seconds», Euphoria: живой = моторы, мёртвый = пассивный |
| 3. Смерть | здоровье 0 | пассивный регдолл (моторы выключены), урон от падения по остановке | Skyrim «Fall damage is not applied […] until […] complete stop» |

Иммунитеты — по массе, а не по списку: KNOCKDOWN_DV в м/с делает мамонта
несбиваемым естественно (J/m мал), без исключений Skyrim. Гипер-броня (DS3)
— множитель стойкости в окнах атаки (флаг из клипа атаки).

Закон сохранения импульса: удар персонажа по НПС — обмен J: НПС получает +J
(ярус 0…2), атакующий получает −J/… не полностью: он стоит на ногах и
опирается о землю; честно — отдача −J·RECOIL_SHARE (Skyrim «you are recoiled
25% less» — у них отдача тоже доля). Владелец прав: «если я кого-то ударю, я
должен замедлиться» — Δv атакующего = −J·RECOIL_SHARE/m, и это будет видно
на беге в толпу.

## 3. Что нужно от контракта физики (зона лида)

1. `character_add_impulse(handle, J)` и масса персонажа в CharacterDesc
   (mass_kg → CharacterVirtual::SetMass) — ярус 0.
2. Контакты капсулы наружу: `character_contacts(handle)` → {тело, нормаль,
   относительная скорость, масса тела} за шаг — источник J от толчков
   (CharacterContactListener::OnContactAdded); с mCanPushCharacter по массе:
   тело легче CHARACTER_PUSH_MASS_KG толкается персонажем, тяжелее —
   толкает его.
3. Регдолл: `create_ragdoll(skeleton, hitboxes) → RagdollHandle`,
   `ragdoll_set_pose`, `ragdoll_add_impulse(part, J)`,
   `ragdoll_drive_to_pose(pose, strength)`, `ragdoll_pose()`.
4. Болванчик: тот же регдолл на стенде stands/character, подвешенный
   констрейнтом за макушку («груша») или стоящий с моторами (активный) —
   прибор для ударов: импульс от клинка по хитбоксу → отклонение, время
   возврата, счётчики.

## 4. Что делает линия персонажей

- HitReaction-роли в ClipLibrary (Mixamo: hit reactions, knockdown, get up —
  в паках Sword and Shield / Action Adventure — проверить по именам).
- Стойкость и ярусы — BodyDrive получает `impulse_model` за тик, ClipPlayer
  выбирает реакцию по направлению и ярусу; переход в регдолл и обратно —
  SkinnedCharacter (поза ↔ Ragdoll::SetPose/GetPose).
- Приборы: стенд «болванчик» (п. 3.4) + LocoTelemetry для яруса 0 (толчок →
  капсула и стопы: держит/переступает/скользит).

## 5. Порядок и цена

1. Контракт: масса + импульс персонажу + контакты (лид, ~день) → ярус 0 с
   §11-ногами (я, день после §11).
2. Стойкость + стаггер-клипы (я, день; реестр POISE_*).
3. Регдолл из хитбоксов + болванчик на стенде (лид контракт ~2 дня, я
   переходы ~2 дня).
4. Обмен импульсом при ударе оружием (после хитбокс-контакта клинка).

Реестр (предварительно, утвердить на синке): CHARACTER_MASS_KG 80,
POISE_HEALTH 100, POISE_REFILL_S 5, KNOCKDOWN_DV_MPS 2.5, KNOCKDOWN_LIMP_S 0.4,
RECOIL_SHARE 0.25, CHARACTER_PUSH_MASS_KG 40.
