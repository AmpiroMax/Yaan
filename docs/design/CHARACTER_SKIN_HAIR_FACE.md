# Кожа, волосы, лицо — записка проекта

## 1. Что уже есть

**В движке.** `platform::SkinnedVertex` несёт `uv` и `color_rgba`; импортёр
glTF читает TEXCOORD_0 в `v.uv` (tools/import_gltf.cpp), то есть развёртка
доезжает до .dfo. Фрагментный шейдер реквизита `fs_prop.sc` уже семплирует
`s_texColor` (альбедо) и `s_texAux` (лист рельефа); скиннинг рисуется
программой vs_skinned + fs_prop_mtl, но текстуры к скиннингу сейчас не
привязываются — цвет идёт палитрой (`--skin-palette`, маска DEF-head). Тени
для вырезов есть (`fs_shadow_cutout.sc`) — пригодятся волосам.

**В инструментах.** Тело печёт `tools/make_human_body.py` из MPFB 2.0.17
(Blender 5.2.1), детерминированно, с анимациями двух доноров. MPFB системные
ассеты (CC0) стоят в профиле Blender:
`.../extensions/.user/blender_org/mpfb/data/`:
- `skins/` — 19 наборов: young/middleage/old × african/asian/caucasian ×
  female/male, toon01, special suit; каждый — материал с альбедо/нормалью;
- `hair/` — 10 причёсок: afro01, bob01, bob02, braid01, long01, ponytail01,
  short01–04 (меши-карты с альфой);
- `eyebrows/`, `eyelashes/`, `eyes/`, `teeth/`, `tongue/` — сопутствующие
  меши и текстуры;
- `targets/` — цели лица и тела (одних глаз 68 целей), из которых уже
  собирается HumanBase.morf (10 целей) для экрана создания.

Лицензии: MPFB и его системные ассеты — CC0 (assets/objects/characters/MPFB_LICENSE.txt).

## 2. Архитектура

**Кожа.** Один базовый альбедо кожи (2K, из набора MPFB, выбранного по
расе/возрасту/полу персонажа) + нормаль. Поверх — СЛОИ в той же развёртке:
грязь (маска + тон), шрамы (набор декалей по регионам: лицо, грудь, спина,
руки), раскраска/татуировки, загар/бледность (множитель тона). Композит —
при загрузке персонажа в одну текстуру (CPU или один проход в bgfx во
внеэкранный буфер), в кадре — обычный семплинг: никакой многослойности в
шейдере, НПС-толпа не дорожает. Описание слоёв — плоские данные в
`.people`/спеке персонажа (правило 8), чтобы Ульфрик был «база nord_male +
шрам_лицо_02 + грязь 0,3».

**Волосы.** Меш-карты MPFB (alpha cutout), скиннинг к DEF-head (и к шее для
длинных), свой материал с вырезом и двусторонним освещением; тень через
fs_shadow_cutout. Физика волос — не сейчас (см. CLOTHING_AND_CLOTH.md, тот же
механизм мягких тел Jolt для длинных причёсок позже).

**Лицо.** Цели MPFB — уже наш путь (.morf, дельты вершин, применяются в
MorphBlend). Расширить набор: глаза (68 целей), нос, рот, подбородок, скулы,
уши, челюсть — по группам MPFB; экран создания (CHARGEN_UI.md) получает
ползунки по группам и пресеты «раса/возраст». Глаза/брови/ресницы/зубы —
отдельные меши из MPFB, привязанные к тем же суставам; цели лица должны
двигать и их (MPFB даёт цели и для глазных яблок — проверить).

**Что нужно от импортёра и реестра.** Секция TEX в .dfo (или ссылка на PNG
рядом с .dfo — решить с лидом; ссылка проще для итераций художника), загрузка
в bgfx, привязка `s_texColor`/нормали к скиннингу; несколько мешей на одного
персонажа (тело, волосы, глаза, брови) с общей палитрой суставов.

## 3. Волны

1. **Текстура на скиннинге** (движок, лид): импортёр не выбрасывает текстуры
   glb, реестр грузит альбедо/нормаль, скиннинг семплирует. Прибор: стенд с
   персонажем в шахматной тестовой текстуре — швы UV видны сразу.
2. **Кожа из MPFB** (Blender-агент): make_human_body.py экспортирует материал
   кожи (альбедо/нормаль) в glb; композит слоёв (грязь/шрамы) — сначала
   офлайн в инструменте (PNG на персонажа), потом в движке при загрузке.
   Прибор: стенд крупно (DFN_STAND_CAM=4), сравнение с референсом Skyrim
   (artifacts/reports/…, кадры владельцу).
3. **Волосы, глаза, брови, зубы** (Blender-агент + движок): меши MPFB как
   доп. меши персонажа, вырез + тень.
4. **Лицо конфигурируемое** (лид + Blender-агент): наборы целей по группам,
   экран создания, пресеты; Ульфрик как пресет — proof of concept.
5. **Слои кожи в движке** (грязь/шрамы/раскраска из спеки персонажа,
   композит при загрузке) — после того, как базовая кожа стоит.

Порядок волн — лиду; выпечка и всё, что в Blender, — Blender-агенту (эта
сессия); рендер — рендер-агенту лида.

### 3.1. Волна 5 сдана офлайн-композитом (07.09)

`tools/skin_layers.py` (numpy + Pillow, conda) собирает из альбедо набора
MPFB и спеки персонажа `assets/characters/skins/<имя>.skin` (JSON) два листа:

- **albedo.png** — грязь по областям тела (доли в спеке: кисти 0,55, стопы
  0,6, голени 0,35, предплечья 0,35, голова 0,22…) зерном шума и сгущением в
  складках; шрамы — отрезки в UV (щека, бровь, живот, плечо) бледнее и чуть
  розовее СВОЕЙ кожи, мягкие края;
- **normal.png** — поры (шум значений, 3 октавы), рельеф из альбедо (тёмные
  складки — впадины), рубцы шрамов (гребень с канавкой); tangent space, +Y
  вверх по листу.

Области — не нарисованные маски, а растеризация треугольников самого glb по
доминирующей кости (голова/кисть/предплечье/плечо/корпус/бедро/голень/стопа):
маска не разъедется с телом, пока тело — контракт. Листы идут в выпечку
(`make_human_body.py --skin-albedo … --skin-normal …`), та кладёт их рядом с
glb, пишет SHA256SUMS и LICENSE (производная того же CC0), glb получает
`normalTexture`; импортёр даёт роль `normal` в TEX, `CharacterTextures::
body_normal_asset` поднимает лист, `SkinnedDraw::normal_asset` — как у частей.
Меш тела бит в бит (sha c119949e…), клипов 182.

Приёмка — стенд персонажа, камера 6 «лицо» (новая: фронт, 0,45 м; тело на
стенде смотрит В ОБЪЕКТИВ, на остальных камерах взгляд гасится — иначе слой
взгляда §13.6 тянул голову на 60° за рыском орбитальной камеры):
`artifacts/reports/blender-agent/61_face_skin_layers.png`, общий план
`61_front_viking.png`, карта грязи `61_dirt_map.png`. Камеры 1–4 стенда
пересняты (якорь стрелы над головой, фигура сидела в нижней четверти кадра).

Что дальше по коже (по приказу владельца 07.09 — лицом долго не заниматься):
шероховатость/спекуляр кожи (рендер, одна роль roughness), паки skins02
(викинг с татуировками, славяне, веснушки — установлены в MPFB) как варианты
народов `assets/characters/peoples/*.people`, слои в движке при загрузке
(волна 5 «в движке») — когда появится второе тело.
